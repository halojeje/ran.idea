Kami berkomitmen untuk melindungi dan menghormati privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami mengelola informasi Anda saat menggunakan aplikasi ini.

Aplikasi ini menyimpan data ide desain yang Anda tandai sebagai favorit secara lokal di perangkat Anda (Local Storage/SharedPreferences). Kami tidak mengumpulkan informasi identifikasi pribadi seperti nama, email, nomor telepon, atau lokasi GPS.

2. Penggunaan Informasi

Data yang tersimpan di perangkat Anda hanya digunakan untuk menampilkan kembali daftar favorit Anda di dalam aplikasi.

3. Penyimpanan Data

Semua data disimpan secara lokal di perangkat Anda dan tidak diunggah ke server luar milik kami.
